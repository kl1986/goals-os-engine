# Daily note's `## Project next actions` now sources ticket frontmatter, and includes Areas

`daily-note.md` v1 sourced `## Project next actions` by scanning `projects/*/*.md` for `status: Active` and taking the first unchecked `## Next action` line — Areas were never in scope, and write-back matched by verbatim line text via a hidden `<!-- daily-note-src -->` comment, because the visible text could drift from the source. ADR-0017 removes `## Next action`, so this sourcing has to change regardless; while doing so, scope was deliberately widened to include Areas (`tasks/areas/<slug>/`) alongside Projects (`tasks/projects/<slug>/`), since both now share the same ticket schema and there's no structural reason to exclude one. Decided 22/07/2026.

New sourcing: every ticket with `status: prioritised` or `status: in-progress` under `tasks/projects/*/` or `tasks/areas/*/` renders as one daily-note row (`- [ ] {ticket title} — [[<ticket>]]`, linked straight to the ticket file, not the parent note) — no per-Project/Area cap, since each ticket already carries its own priority signal. Projects still gate on the parent Project note's own `status: Active` (Complete/Incubating Projects stay silent even if a stray ticket is prioritised); Areas have no equivalent lifecycle field, so their tickets surface unconditionally. Because the row now links directly to a stable ticket file rather than matching verbatim text, the `daily-note-src` comment is dropped — Close daily note resolves the wikilink and writes `status: done` + `resolved: <date>` straight to the ticket, with no second store to reconcile.

**Rejected:** capping at one ticket per Project/Area (old "first line only" behaviour) — rejected because it would silently hide already-prioritised tickets, the opposite of what prioritising them was for.

**Consequences:** `## Project next actions` as a heading name is now a slight misnomer (it also carries Area tickets) but is being kept as-is per this session's scope decision; a rename is a candidate follow-up, not required by this ADR.
