# The Build plugin vendors its engineering skills rather than depending on them

The `/build` plugin bundles its own copies of the software-engineering skills it runs (the `implement`, `tdd`, `to-tickets`, `code-review`, `claude-handoff` and `resolving-merge-conflicts` family) instead of invoking the installed originals. The forcing constraint is mechanical, not stylistic: `implement`, `to-tickets`, `to-spec`, `claude-handoff`, `wayfinder` and `grill-with-docs` all carry `disable-model-invocation: true` upstream, so **no agent can invoke them on any install** — four of them sit squarely on the pipeline's critical path, including the `/claude-handoff` step the earlier prompt marked MUST. Vendoring also makes the plugin self-contained on a bare Goals OS install, with no probing and no degradation paths. Decided 23/07/2026.

**Considered options.** *Inline only the four blocked skills and call the rest* — vendors the minimum and keeps upstream fidelity where upstream actually works, but leaves the plugin's behaviour dependent on what happens to be installed. *Declare them a hard requirement and pause for the user to type the blocked commands* — perfect fidelity, but multiple mandatory human pauses per Ticket, which is incompatible with ADR-0023. *Have plugin setup strip the `disable-model-invocation` flag from the installed copies* — least duplication, but it mutates another author's files, overrides a deliberate upstream decision, and breaks on their next update.

**Consequences — publication is blocked.** The Library is MIT-licensed and its README describes plugins as meant to be published and forked by anyone, but the vendored skills carry **no licence file and no known grant**. The plugin therefore ships **private, not for publication**, with a `NOTICE` file recording each vendored skill's origin and its unresolved licence status. Clearing that grant is a tracked blocker on making the Library public. Separately, vendored copies drift from upstream by construction — the `NOTICE` file records the version vendored so drift is at least visible.
